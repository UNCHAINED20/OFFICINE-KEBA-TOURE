# KÉBA PHAR — Prototype Web V1.1

Prototype front-end HTML/CSS/JavaScript inspiré du prototype UI/UX fourni, enrichi d'un écran de connexion et de micro-interactions.

## Accès de démonstration
- Nom : votre nom
- Code : `KEBA`

La connexion est une authentification de démonstration locale uniquement. Elle n'est pas sécurisée et ne doit pas être utilisée telle quelle en production.

## Micro-interactions incluses
- Boutons hover / press / ripple
- Confirmation « ✓ Ajouté »
- Animation produit → panier + bounce du panier + compteur
- Recherche focus + suggestions + résultats
- Favoris ♡ → ♥ avec rebond
- Cartes produits avec élévation subtile
- Skeleton loading sur les catégories
- Toast de confirmation
- Suppression avec fondu + glissement
- Compteurs animés
- Header flouté au scroll + bouton retour en haut
- Révélation progressive des contenus
- Images/visuels avec léger scale au survol
- Respect de `prefers-reduced-motion`

## Lancer
1. Décompresser.
2. Ouvrir le dossier dans VS Code.
3. Installer/activer « Live Server ».
4. Clic droit sur `index.html` → « Open with Live Server ».

## Important
Cette version reste un prototype front-end : pas de vraie base de données, authentification serveur, paiement ou gestion réelle de stock.
